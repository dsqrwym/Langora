# Langora

Langora is a multilingual website and content management system for language schools and overseas mother-tongue education institutions.

**Status: in development.** Nothing here is ready for production use yet.

Planned stack:

- Java 21 source/target level, runtime JDK 25 LTS (any JDK 21+ can build)
- Spring Boot 4 (Spring MVC on embedded Tomcat)
- Vue.js frontend
- PostgreSQL (Flyway migrations, jOOQ)
